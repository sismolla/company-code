Important: Bulk Upload Instructions

Quick Note: If you want to upload your data in excel read this carefully, Required fields: name, strength, price, stock quantity, dosage form.

1. File Structure

The first row of your Excel must contain headers. Common accepted names:

Field Accepted Header Names
Product Namename, product name, product_name
Strengthstrength, dose
Priceprice, cost, unit price
Stock Quantitystock_quantity, stock quantity, quantity, stock, stock qty
Dosage Formdosage_form_id, dosage, dosage form, form
Expiration Date (optional)expire_date, expiry, expire date, expiry date, expiration date

2. Supported Dosage Forms

These are the accepted dosage forms (case-insensitive). The system will attempt flexible matching if the exact form is not found:

  • Tablet, Capsule, Injection, Syrup, Suspension
  • Cream, Ointment, Gel, Lotion, Suppository
  • Powder, Inhaler, Patch, Granules, Mouthwash
  • Lozenge, Solution, Emulsion, Spray, Chewable Tablet
  • Effervescent Tablet, Dispersible Tablet, Extended/Controlled Release Tablet, Sachet, Ampoule
  • Vial, Powder for Injection, Infusion Solution, Shampoo (Medicated), Dental Paste
  • Nebulizer Solution, Nasal Spray, Eye Drops, Eye Ointment, Ear Drops
  • Nasal Drops, Enema, Vaginal Tablet, Vaginal Cream, Buccal Film/Tablet
  • Sublingual Tablet, Implant

3. Data Rules

  • Required fields: name, strength, price, stock_quantity, dosage_form_id.
  • Dosage Form must match one of the supported forms; flexible matching will attempt to find close variations (e.g., "tablet coated" → "Tablet").
  • Expiration Date is optional; if present, it must be a valid date (YYYY-MM-DD or MM/DD/YYYY).

4. Upload Behavior

  • Existing products (same name, strength, dosage form, supplier) are updated.
  • New products are created if no match exists.
  • Errors are recorded per row; upload continues even if some rows fail.
  • Ambiguous dosage forms are logged; the system picks the closest match automatically.

5. Post-Upload Feedback

  • Success: shows how many new products were created and how many existing products were updated.
  • Errors: lists row numbers with problems for easy correction.
  • Warnings: lists rows where dosage form was ambiguous or auto-corrected.
